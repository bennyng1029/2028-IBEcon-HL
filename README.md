# Economics Lab

Open `index.html` in a modern browser, or serve this directory with any static web server. All scripts and assets are local; there is no build, account, runtime network request, or dependency installation. Relative paths also support a subpath deployment. Select English, Japanese, Korean, or Hong Kong Traditional Chinese manually.

The guided release covers Units 1–2 (14 lessons); Units 3–4 are forthcoming. The 113-point coverage inventory now records 101 taught points, 12 compressed summaries, and no omitted points within that inventory. The 40 previously omitted diagram objectives link directly to localized guided studios. This inventory is not a claim of exhaustive syllabus coverage. Models use illustrative values and explicit simplifying assumptions. Original practice and rubrics are not official IB questions or markschemes. English economic terms and written-answer scaffolds remain visible. Progress is stored locally when permitted and can be reset; blocked storage leaves the learning content available for the current visit.

This independent resource is not an IB product. Its detailed baseline is the October 2022 guide, first assessment 2024; Paper 2 covers common material, with HL extensions marked separately. Consult the school's current guide and session notices. Run `node --test tests/*.test.js` for content, model and interface checks. Browser verification should include file and subpath HTTP launch, all language/model combinations, keyboard controls, mobile layout, quiz feedback, storage blocked and available, and malformed hashes. Automated checks do not establish curriculum completeness or independent translation quality.

The original release verification is recorded in [initial closeout](docs/closeout.md). The expanded diagram release and its verification, review evidence, and remaining limitations are recorded in [diagram closeout](docs/diagram-closeout.md).

Forty guided diagram studios offer 67 finite scenarios in all four languages, independently of the existing calculators. Open a studio, predict, choose each drawing layer, compare the initial and final diagrams, and explain the mechanism. Wrong choices give feedback without adding a layer. Reveal shows the construction and is explicitly distinct from completing practice; reset clears attempts and layers. Optional HL quantitative checks have their own labelled disclosure. Coordinates and data illustrate assumptions; this guided recognition and construction does not establish independent drawing mastery. Coverage activation was independently verified against the frozen 40-objective scope.

Use native Tab/Shift+Tab navigation, Space for choices/disclosures and Enter for buttons. Numbered diagram marks correspond to the full localized HTML legend. Complex diagrams retain a readable 800px canvas inside a focusable horizontal scroll area; scroll locally to inspect the whole drawing. Initial descriptions and legends include only currently visible geometry. Changing language resets transient studio practice and announces that policy while retaining the lesson and saved completion.

The browser harness needs an existing local Chrome CDP endpoint at `127.0.0.1:9222` and a workspace-only HTTP server on port 8765 mapping `/course/` to this directory.
