# Economics Lab

Open `index.html` in a modern browser, or serve this directory with any static web server. All scripts and assets are local; there is no build, account, runtime network request, or dependency installation. Relative paths also support a subpath deployment. Select English, Japanese, Korean, or Hong Kong Traditional Chinese manually.

The guided release covers Units 1–2 (14 lessons); Units 3–4 are forthcoming. The coverage matrix distinguishes taught points, compressed summaries, and omissions, including missing diagrams. Models use illustrative values and explicit simplifying assumptions. Original practice and rubrics are not official IB questions or markschemes. English economic terms and written-answer scaffolds remain visible. Progress is stored locally when permitted and can be reset; blocked storage leaves the learning content available for the current visit.

This independent resource is not an IB product. Its detailed baseline is the October 2022 guide, first assessment 2024; Paper 2 covers common material, with HL extensions marked separately. Consult the school's current guide and session notices. See [source validation](docs/research/source-validation.md) and [curriculum research](docs/research/curriculum.md) for evidence and limitations.

Run `node --test tests/*.test.js` for content, model and interface checks. Browser verification should include file and subpath HTTP launch, all language/model combinations, keyboard controls, mobile layout, quiz feedback, storage blocked and available, and malformed hashes. Automated checks do not establish curriculum completeness or independent translation quality.
